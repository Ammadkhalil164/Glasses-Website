### 1. 3D Engine Setup (`index.html`)
Establish a full-viewport, fixed canvas (`#glasses-canvas`) behind the UI. Write a vanilla JavaScript/ES Module script block to set up the Three.js scene, lighting, camera, and ScrollTrigger animations:

1. **3D Model Loader**:
   - Use `GLTFLoader` and `DRACOLoader` (with decoder from GStatic CDN).
   - Load the public 3D glasses model GLB directly from GitHub: 
     `https://raw.githubusercontent.com/Ammadkhalil164/3d-Glasses-By-Ammad/main/black_glasses%20(1).glb`
   - Center the model locally on load using `Box3` and calculate its dimensions to scale it uniformly (`baseScale = 2.2 / maxDim`).
2. **Anti-Reflective Materials**:
   - Override model materials on traverse: Set deep matte black (`color: 0x1a1a1a`), metalness `0.2`, roughness `0.3`, and set `envMapIntensity` to a low value (like `0.2`) to suppress blue/teal environment reflections.
3. **Screen-to-World Coordinate Mapper**:
   - Write a helper to translate DOM element bounding box screen coordinates (x, y) into 3D world space (Z = 0) so the 3D glasses can land precisely inside CSS layout blocks on scroll.
4. **GSAP Scroll Spline Animation**:
   - Setup a `CatmullRomCurve3` path connecting 5 waypoints representing sections:
     - **Waypoint 0 (Hero)**: Center of viewport `(0, 0, 0)` in front of the main title.
     - **Waypoint 1 (Stats/Cards)**: Center of card 1 landing zone.
     - **Waypoint 2 (Interactive Viewport)**: Center of the relative WebGL frame.
     - **Waypoint 3 (Achievements)**: Landed in the next block.
     - **Waypoint 4 (Closing/Mistake)**: Final position.
   - Bind GSAP ScrollTrigger to interpolate the model's container position along the S-curve path based on overall scroll progress (`0.0` to `1.0`).
   - Implement Bezier curves to smoothly transition the model scale and rotation when moving between waypoints.
   - Add a subtle settle bounce rotation (`gsap.to` with yoyo: true) when arriving at waypoint triggers.
5. **Mouse Drag & Hover Rotation**:
   - Use `Raycaster` to detect when the mouse pointer is hovering over the model. Change the cursor style to `grab`/`grabbing` and enable interactive dragging.
   - Smoothly interpolate target Y-axis (yaw) and X-axis (pitch) rotations based on mouse movements, returning to automatic idle spinning when not dragging.
